## Completed connection

The dormant Serving load owner holds the actual invocation and run locks across
indexed selection, preparation, process startup, the original Enter answer and
rollback. It refuses an existing run or recorded live constituents before selecting
or starting anything, and never ends that earlier run. Root authentication and the
existing cause rule guard its production entry.

Selection reuses the strict descriptor-based restore-artifact reader and the
artifact repository's latest-only rule. It parses the judged territory draft for
independent session/path comparison. It performs operational inventory against the
verified artifact copy, not the draft's operational settings. It publishes no room
leftovers and does not fall back to an older artifact. Both locks still stand when
the complete Enter is prepared; an oversized encoded frame refuses before any fork
with enter_frame_too_large and DescriptorsUnusable.

The owner opens the sink, prepares runtime/log custody, makes the root-owned
recorded cgroup and rebuilds elected shell commands. A file sink uses the existing
trace-relay start step. A new fixed Serving member launch receives the retained
read-only image at fd4, its existing first channel at fd3 and the shared run lock
at fd9. It receives --mode=serving, no configuration or artifact pathname. Cgroup
placement precedes the restricted identity and descriptor allowlist. Its environment,
working directory, mask, signal reset and no-new-privileges setting are explicit.

The worker uses the existing root spawn primitive and inherited run lock/relay
lifetime. The existing classifier-executable argument carries the judged STE100
binary to the eventual replacement worker. The old worker cannot consume this
paired Enter; this module does not activate either dispatcher. After the actual
credential/run-lock peer judgment, admin sends the exact prepared Enter with the
trace sink and the same state endpoint. Admin never reads the state exchange.

Only Ready at Close on that exact exchange, inside the existing answer-wait bound,
permits the durable open marker and the retained replacement loaded-state facts.
Refusal, EOF, timeout, wrong exchange/position and failed starts reach the existing
rollback owner. A successfully sent Enter owes its explicit rollback Leave. Cleanup
failures retain both the initial cause and the cleanup refusal. Direct children are
retained through rollback and reaped where ended; recorded containment owns the
whole process set. No failed start reports Loaded.
